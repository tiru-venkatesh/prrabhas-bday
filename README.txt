REBELVERSE — TOLLYWOOD STRIKE · REBELWOOD
Prabhas fan tribute website

WHAT'S INCLUDED
- index.html: the complete responsive fan site, full-screen hero, left/right movie slideshow, Top Hits carousel, birthday countdown and age counter, fan-edit showcase, wishes wall, movie poster archive, upcoming films, awards and floating Pandagala YouTube player.
- assets/posters/: 29 connected images: the cover artwork, 24 images supplied in posters.rar (including the cover), and four next-era posters for Salaar 2, Spirit, Fauzi and Kalki 2.

POSTER ARCHIVE
The archive includes Eeswar, Raghavendra, Varsham, Adavi Ramudu, Chakram, Chatrapathi, Pournami, Yogi, Munna, Bujjigadu, Billa, Ek Niranjan, Darling, Mr. Perfect, Rebel, Mirchi, Baahubali: The Beginning, Baahubali 2: The Conclusion, Saaho, Radhe Shyam, Adipurush, Salaar, Kalki 2898 AD, The Raja Saab, plus the supplied upcoming-film posters and the Prabhas cover artwork. Poster images are optimized for faster loading and retain their original aspect ratios.

TOP HITS SLIDESHOW
Six featured films: Mirchi, Baahubali, Baahubali 2, Darling, Salaar and Kalki 2898 AD. Automatic rotation runs every 5.5 seconds, with previous/next arrows, dots and keyboard arrow navigation. All six have local poster artwork.

UPCOMING HERO SLIDESHOW
The landing hero fills the viewport below navigation. The background poster art fades from transparent on the left to vivid on the right. The active Salaar 2, Spirit, Fauzi or Kalki 2 poster stays in the center-right, with neighboring slides fading to either side. It auto-advances, supports swipe on touch devices, keyboard arrows, clickable side slides and indicator dots.

PANDAGALA MUSIC
The floating PLAY PANDAGALA button opens a YouTube player that remains available while visitors scroll. One tap is needed to begin playback because browsers block sound autoplay before user interaction. The song is streamed from YouTube; no audio file is bundled.

PREVIEW / PUBLISH
1. Extract this ZIP.
2. Open index.html in a browser to preview it. For best results, run it through a local static server or publish the whole folder.
3. Keep index.html together with the assets/ folder; do not upload only index.html.
4. Publish the extracted project folder using Netlify Drop, GitHub Pages or Vercel static hosting.

IMPORTANT
This is an unofficial fan-made tribute and is not affiliated with Prabhas or his representatives, film studios or media rights holders. Only publish media you have permission to use. Public fan wishes and edit submissions in this static demo are stored in each visitor's own browser and are not shared across visitors without a backend.
